A pseudo-element allows you to style or create a specific part of an HTML element. 

        ::before
        ::after
        ::first-letter
        ::first-line
        ::selection
        ::marker

::before

::before creates a pseudo-element before the content of an element.

Example :

Hello Kunal!

::after

::after creates a pseudo-element after the content.

Example

Hello KK

::first-letter

::first-letter selects the first letter of text.

Kunal Kavathekar

only first letter K is affected

::first-line

::first-line styles the first line of text inside an element. Only the first displayed line gets the style. The first line depends on the available width. For example, if you resize the browser, the words belonging to the first line can change.

::selection

::selection styles text when the user selects/highlights it with the mouse or keyboard.

::marker

::marker allows you to style the marker of list items.
